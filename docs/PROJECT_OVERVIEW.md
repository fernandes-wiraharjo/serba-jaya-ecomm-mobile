# Gambaran proyek

Serba Jaya Ecommerce adalah kanal belanja pelanggan. Aplikasi meliputi penelusuran produk oleh tamu dan pengalaman belanja berbasis akun. Admin dan GF adalah sistem terpisah. Lihat [cakupan dan batas sistem](requirements/SCOPE.md).

| Area | Teknologi |
|---|---|
| Platform | Android, iOS |
| Framework | Flutter Stable, Dart |
| Aplikasi | Modular monolith, Feature-first Clean Architecture, MVVM pragmatis |
| Bahasa | UI dan dokumentasi Bahasa Indonesia, penamaan kode bahasa Inggris |
| Target Phase 1 | Proyek dapat dibangun dan divalidasi tanpa layanan eksternal |

Desain, kontrak backend, kredensial provider, dan implementasi bisnis memiliki jalur persetujuan tersendiri. Rujuk [status proyek](PROJECT_STATUS.md).
