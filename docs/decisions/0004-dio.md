# ADR 0004 — Dio

**Status:** diterima untuk Phase 1.

Gunakan Dio dengan konfigurasi bersama, injeksi autentikasi eksplisit, dan error mapping pada batas repository. Dio mendukung JSON, multipart, timeout, dan pembatalan tanpa wrapper tambahan. Redirect HTTP dan retry otomatis dinonaktifkan atau tidak dipasang untuk menghindari pengiriman ulang transaksi dan token lintas tujuan.
