# Pertanyaan terbuka

| Topik | Keputusan yang dibutuhkan |
|---|---|
| Pembatalan dan refund | §2.7 menyebut pembatalan saat membuat pesanan. §2.12 dan §7 mengecualikan refund/pembatalan. Konfirmasi cakupan, pihak yang boleh membatalkan, status, dan efek terhadap stok, pembayaran dan reward. |
| Autentikasi | Konfirmasi kontrak pertukaran token, validasi sesi, registrasi parsial, expiry, refresh, revokasi dan logout. Tentukan akun bertaut, duplikasi email/telepon, serta hapus akun. Konfirmasi dokumen legal, opsi gender, dan aturan validasi field sebelum Form Daftar diaktifkan untuk pengiriman. |
| Proteksi fitur | Konfirmasi detail aksi produk, akses alamat dari beranda, dan kapan meminta login saat pengguna memilih pengiriman. |
| Pesanan dan pengiriman | Status dan transisi resmi, SLA, zona waktu slot, batas pemesanan, cakupan area, aturan biaya/radius, self pickup dan batas stok. |
| Pembayaran | Rekening resmi, tipe/ukuran file, batas waktu, status verifikasi, koreksi dan upload ulang bukti. |
| Harga, promosi dan poin | Aturan harga member/bertingkat, penumpukan voucher, batas pemakaian, dasar pembulatan poin, kedaluwarsa, dan peristiwa pemberian poin. |
| Komisi Marketing | Dasar nilai penjualan, awal kelayakan, dampak status member, pembulatan, minimum penarikan, serta alur dan status pembayaran. |
| Dokumen membership | Format, ukuran, retensi, persetujuan privasi, penolakan dan pengajuan ulang. |
| WhatsApp dan lokasi | Nomor resmi, format pesan dan fallback, penyedia peta serta kebijakan izin. |
| Push | Penyedia, registrasi perangkat, preferensi, payload dan kebijakan deep link. |
| GF dan backend | Mapping, kepemilikan data, pengurangan stok, sinkronisasi, retry dan akses. Tetap lintas tim melalui backend. |
| Signing dan OAuth rilis | ID aplikasi resmi sudah disetujui dan diterapkan. Siapkan signing release, verifikasi app signing key di Play Console, Apple Team ID/provisioning, domain callback, dan client OAuth setelah akses serta persetujuan tersedia. |
| Desain navigasi dan Header | Nilai navigasi tersimpan dalam catatan inspeksi sebelumnya; screenshot dan aset ekspor tidak tersedia lokal, sedangkan MCP saat ini dibatasi paket Starter. Implementasi memakai token terdokumentasi dengan ikon dan treatment badge provisional. Ekspor screenshot section 390 × 90, empat pasangan SVG ikon tab, aset tombol/dudukan dan mask Chat, aset/spesifikasi badge, serta screenshot dan properti untuk setiap varian Header. Konfirmasi aturan badge dan layar yang menampilkan Header sebelum verifikasi visual. |

Rujuk [API](../integrations/API.md), [autentikasi](../integrations/AUTHENTICATION.md), dan [GCP OAuth](../integrations/GCP_OAUTH.md) sebelum integrasi.
