# ADR 0003 — GoRouter

**Status:** diterima untuk Phase 1.

Gunakan GoRouter untuk daftar rute, shell, dan guard yang bereaksi terhadap sesi. Setelah login, lanjutkan hanya ke path terlindungi yang diizinkan. Deep link native dan bentuk parameter per fitur akan ditentukan ketika rute final disetujui.
